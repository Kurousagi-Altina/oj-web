# 100% Orange Juice — Web Replica (Demo)

原作《100% Orange Juice》(Orange_Juice / Fruitbat Factory) 的网页复刻 Demo。
纯静态站点(HTML/JS/CSS),无构建步骤,可部署到任意静态服务器。

## 运行

```bash
python -m http.server 8123 --directory web
# 或 npx serve web
```

打开 http://localhost:8123 → 选择地图与角色开始游戏(1 人 + 3 CPU)。

## 还原标准(全部对照官方 Wiki)

本项目的规则与地图**逐页对照 100% Orange Juice Wiki** 实现,
不采用想当然的设定:

### 角色(基础版 10 人 + 彼特,数值取自 Wiki 角色页)
QP / 须玖莉 / 玛露 / 凯 / 亚露 / 姬梅 / 由希(5/+2/-1/-1,赌博!)/
优空(4/+1/0/+1,荒唐的性能)/ 玛丽啵噗(7/-1/-1/-1,神出鬼没)/
兔萌萌(4/+2/0/0,杀戮魔法)/ 彼特(3/+1/+1/+1,湛蓝乌鸦·再临)
- 专属 Hyper 均已实现效果(赌博随机击倒、本章掷6、偷星瞬移、
  满血全灭+降REC、战斗按手牌数加攻防)

### 画面表现
- 与原作一致的**等距(isometric)伪 3D 呈现**:面板为 2:1 菱形瓷砖,
  整个棋盘呈菱形铺开(投影方式对照 Wiki 的游戏内截图),
  角色为直立的看板精灵,带彩色光环与投影,按格子深度排序绘制,
  面板带轻微漂浮动画,草地横幅背景
- **掷骰特写演出**(原作方式):角色小人滑入特写、蓄力抛出骰子,
  骰子凌空翻滚(原版 Default Dice 1-6 面图)后落定,显示的点数
  就是实际掷出的值;掷骰是手动操作(点「掷骰子！」按钮),不会自动跳过

### 地图(布局图逐格转录)
- 开始页面可选择 3 张地图,布局均从 Wiki 官方布局图(A-*.png)逐格转录,
  面板构成与 Wiki 各地图页面的面板统计表**完全一致**:
  - **三叶草 Clover**(40 格):Bonus×8 / Draw×4 / Draw×2×4 / Drop×2×4 /
    Encounter×8 / Move×4 / Warp×4 / Home×4;事件:奇迹(每5章)、逆行(每8章);Boss:师傅机器人
  - **练习场 Practice Field**(36 格):Bonus×10 / Draw×10 / Drop×2×4 /
    Encounter×4 / Warp×4;无场地事件;Boss:店长
  - **太空流浪者 Space Wanderer**(44 格):Bonus×12 / Draw×8 / Drop×2×4 /
    Encounter×4 / Warp×12;事件:随机传送(每5章);Boss:店长

### 战斗(wiki/Battle)
- 战斗卡只在**战斗开始时**选择一次;攻击方掷骰(骰值+ATK,最低 1,骰子上限 4 枚)
- 防守方**看到攻击值后**选择 Defend(减伤,最少 1)或 Evade(EVD>ATK 完全闪避,否则吃满)
- 攻防互换一轮结束;小战争 ×2 回合、最终决战最多 10 回合
- **路过对手时提示挑战**(可拒绝继续移动),挑战方为先手
- Rbits 禁止闪避、Shield 无法反击、反转字段等按原文实现

### KO 与复活(wiki/Recovery)
- 对玩家 KO:**+2 WIN** + 一半星星;野怪:+1 WIN;Boss:+3 WIN
- 被野怪/Boss KO 的星星进入其**奖励池**,讨伐者获得全部
- 卡牌/面板导致的 KO 不转移星星与 WIN(火箭明确给 2 WIN)
- 被击倒的单位**留在原地**(失败姿势),复活也在原地,不传送回家
- 复活为**掷骰检定**:需求从 REC 开始,失败每章 -1,降到 1 必成;满血原地复活;
  **恢复骰子由玩家自己掷**(有专门的恢复检定按钮与骰子动画)
- Extend / Hyper Mode 下回合自动复活;强制苏生以 1 HP 原地复活

### Norma(wiki/Norma)
- 章节开始星星 = **章节÷5 +1**(向下取整),被击倒也能获得
- **任意家的面板**落地都会进行 Norma 检定;仅自家可选择性停下
- 星星 10/30/70/120/200;**击杀目标 Lv1 不可选,首次胜场升级需 2 WIN**(Lv2→3),
  之后 5/9/14;Lv4 首次达成触发 Boss 事件

### 面板(wiki/Panels)
- Move 格掷骰追加移动(每回合上限 5 次)、**Warp 格只有停下时才传送**(路过不触发)、
  Home/Heal 各回 1 HP
- 奇迹事件:奖励/掉落/抽卡/移动/遭遇/恢复/伤害格全部双倍化,
  **且每回合开始每人抽 1 张卡**(这是除抽卡格外唯一的常规发卡来源)

### 卡牌(40 张,数值取自 Wiki 卡片页 infobox)
- 名称与描述为游戏内置简中/英文官方文本
- 费用与等级要求全部按 Wiki 校对(如:布丁 L4 免费、小战争 L4/50★、
  最终决战 L4/30★、陷阱类 0★ 设置等)
- **中央卡堆**(wiki/Card Mechanics):4 名牌组混成一副 48 张中央卡堆,
  所有人共用抽牌;每位角色打包 2 张**空白 Hyper**,抽到即变成自己的 Hyper
  (保证 Hyper 浓度);快速验证用随机牌组,未来可做自组卡
- 顶栏实时显示**中央卡堆剩余张数**(🂠 N)
- **没有每回合固定抽卡**:卡片来自开局 1 张、抽卡格、卡牌效果与奇迹事件,
  避免手牌堆积
- **每回合移动前只能使用一张卡**(战斗卡不占此限制)
- **手牌满时抽卡必须选择替换**(选一张手牌丢弃、新卡入手),
  **也可以选择不要新卡**(新卡直接弃掉,手牌保持不变);不会跳过抽取

### 野怪与 Boss
- 野怪与 Boss 为**持久单位**:未被打死时血量跨战斗保留,奖励池(星星)也会累积
- 被击杀后才会出现新的野怪;**Boss 被击杀后立即退出 Boss 状态**(遭遇格恢复,不再刷新)
- 野怪 KO +1 WIN,Boss KO +3 WIN,讨伐者获得其**奖励池**全部星星(被 Boss/野怪
  KO 的玩家半星累积进池,无额外平补)
- 野怪/Boss 战斗中**使用自身属性加值**(小鸡 EVD+1、机器球 DEF+1、店长 ATK+3 等)

### Boss(wiki 各 Boss 页 — Boss 版数值,非角色版)
- 师傅机器人(Boss):HP7 / ATK+2 / DEF+3 / EVD-2
- 店长(Boss):HP8 / ATK+3 / DEF+2 / EVD-1
- 飞天城堡(Boss):HP10 / ATK+2 / DEF+1 / EVD-3
- 野怪:小鸡 HP3/-1/-1/+1、机器球 HP3/-1/+1/-1、海鸥 HP3/+1/-1/-1

## 操作

- 出牌阶段:点击手牌使用(悬停查看效果),或点「掷骰移动」
- **掷骰**:出牌阶段结束后点「掷骰子！」按钮掷骰(小人会跳起投掷,骰子翻滚落定)
- 分岔路口:点击画布上高亮面板选路;路过对手时选择是否挑战
- 经过自家 HOME:可选择停下(Norma 达成时会提示)
- 顶栏:调速(1x/2x/4x)、语言切换(中/EN)、重开

## 部署

任意静态托管均可(nginx / Caddy / GitHub Pages / 对象存储),无后端。

```bash
docker build -t oj-web . && docker run -p 8080:80 oj-web
```

## 目录结构

```
web/
  index.html        入口
  css/style.css     样式
  js/i18n_data.js   由 define 数据生成的中英文案(extract/build_i18n.py)
  js/data.js        角色 / 卡牌数据(官方数值)+ i18n 助手
  js/boards.js      格子地图定义(自 Wiki 布局图转录)
  js/engine.js      游戏引擎(纯逻辑,无 DOM 依赖)
  js/ai.js          CPU 决策 + 无头 IO 适配器
  js/render.js      Canvas 渲染
  js/ui.js          DOM 界面(双语)
  js/main.js        启动 / 地图与角色选择
  assets/           自游戏本体提取的素材
  test/smoke.js     无头模拟测试
```
